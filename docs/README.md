## Page conventions

Each page should contain: status and language links; purpose; requirements or research questions; current hypotheses; evidence and sources; decisions; open questions; and a short change history when the page matures. Use ISO dates (`YYYY-MM-DD`). Prefer primary sources and archived links. Never silently turn a conversation idea into a settled requirement.
