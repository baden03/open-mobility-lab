## Seitenkonventionen

Jede Seite soll enthalten: Status und Sprachlinks; Zweck; Anforderungen oder Forschungsfragen; aktuelle Hypothesen; Belege und Quellen; Entscheidungen; offene Fragen; bei reiferen Seiten außerdem eine kurze Änderungshistorie. Nutze ISO-Daten (`JJJJ-MM-TT`). Bevorzuge Primärquellen und archivierte Links. Eine Idee aus einem Gespräch darf nie stillschweigend zur beschlossenen Anforderung werden.
