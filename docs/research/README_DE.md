# Forschungsnotizen und Gesprächsimport

[English](README.md) · [Dokumentation](../README_DE.md)

**Status:** Arbeitsmethode

Dieser Bereich ist die Eingangsstelle für Gesprächsverläufe, Interviews, Quellenprüfungen, Experimente und ungeklärte Beobachtungen. Rohmaterial belegt, was besprochen wurde—nicht, dass eine Aussage wahr ist oder eine Entscheidung getroffen wurde.

## Vorgeschlagene künftige Struktur

```text
docs/research/
├── conversations/   # datierte, zugeordnete Zusammenfassungen; Rohdaten nur wenn zulässig
├── sources/         # Quellennotizen und Bewertung der Anwendbarkeit
├── experiments/     # Pläne, Datenverweise, Ergebnisse und Grenzen
└── decisions/       # angenommene Entscheidungen mit Begründung und Folgen
```

## Importablauf

1. Datierte Notiz mit Herkunft, Sprache, Beteiligten oder Anonymisierung und Umfang erstellen.
2. Ideen als Beobachtungen, Hypothesen, mögliche Anforderungen, Fragen oder Entscheidungen zusammenfassen.
3. Aussagen anhand von Primärquellen oder Tests prüfen; Unsicherheit und widersprüchliche Belege festhalten.
4. Dauerhafte Punkte in passende Konzept-, Technik-, Regulierungs- oder Fahrplanseiten verlinken.
5. Beide Sprachfassungen aktualisieren oder die Übersetzung als ausstehend kennzeichnen.
6. Datenschutz, Einwilligung, Urheberrecht und Lizenzbedingungen beachten; sensible Rohprotokolle nicht veröffentlichen.

## Vorlage für Notizkopf

```markdown
# Thema — JJJJ-MM-TT

- Status: roh | geprüft | integriert
- Sprache: en | de | gemischt
- Herkunft: Gesprächs-, Interview-, Quellen- oder Testkennung
- Datenschutz: öffentlich | anonymisiert | eingeschränkt
- Zugehörige Seiten: Links
- Übersetzung: vollständig | ausstehend
```

## Erstes Importziel

Die vorherige Diskussion zu deutschen E-Mobilitätsregeln, Bedürfnissen adaptiver Mobilität, doppeltem Muskelkraftantrieb und ruderähnlichem Handantrieb soll als geprüfte Zusammenfassung importiert werden. Rechtliche Aussagen benötigen eine neue Prüfung anhand von Primärquellen, bevor sie in Regulierungsseiten übernommen werden.
