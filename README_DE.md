# Adaptive Cycle

> Eine offene, zweisprachige Erkundung adaptiver persönlicher Mobilität: muskelbetrieben, elektrisch unterstützt, zugänglich und auf den Erhalt von Selbstständigkeit ausgerichtet.

[English](README.md) · [Dokumentationsübersicht](docs/README_DE.md) · [Projektfahrplan](docs/roadmap_DE.md)

## Über das Projekt

Adaptive Cycle ist ein öffentliches Forschungs- und Designprojekt für eine konfigurierbare persönliche Mobilitätsplattform. Untersucht werden Ideen aus den Bereichen Fahrrad, Dreirad und leichtes Elektrofahrzeug, ohne anzunehmen, dass eine Bauform zu allen Menschen und Wegen passt.

Die Arbeitspersona **Ol’ Captain Hinkebein** hilft uns, reale Anforderungen zu besprechen, ohne eine bestimmte Person zu identifizieren. Sie ist ein Designhilfsmittel, keine medizinische Bezeichnung und keine Definition der Zielgruppe.

Dieses Repository beginnt als strukturiertes Notizbuch. Die beschriebenen Konzepte bleiben Vorschläge, bis Berechnungen, Prototypen, Tests und—wo erforderlich—fachliche rechtliche oder medizinische Prüfungen vorliegen.

## Entwicklungsziele

- Selbstständigkeit, Würde und Freude an eigener Bewegung bewahren.
- Fuß-, Hand- und Elektroantrieb sinnvoll kombinieren.
- Sicheres Einsteigen, Anfahren, Fahren, Anhalten und Parken unterstützen.
- An veränderte Fähigkeiten und unterschiedliche Wege anpassbar sein.
- Sicherheit, Wartbarkeit und rechtmäßige Straßennutzung sichtbar mitentwickeln.
- Forschung und Entscheidungen auf Englisch und Deutsch veröffentlichen.

## Sicherheits- und Rechtshinweis

Dieses Repository enthält vorläufige technische und regulatorische Forschung, keine zertifizierte Konstruktion, medizinische Beratung oder Rechtsberatung. Baue oder betreibe kein Fahrzeug allein auf Grundlage dieser Notizen. Sicherheitskritische Arbeiten erfordern geeignete Analysen, Tests und qualifizierte Prüfungen. Vorschriften hängen von Fahrzeugklasse, Konfiguration, Ort und Zeitpunkt ab; sie müssen anhand aktueller Primärquellen geprüft werden.
